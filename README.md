Entrants submit a single line, under 200 characters, of awkward small talk that one robot says to another while they ride an elevator together. A judge model reads the lines two at a time against a brief published with the bounty and picks the funnier one, weighing whether it is really a robot's elevator line, whether machine logic shows through, whether the awkwardness lands, and whether it is funny on the first read.

`main.ts` writes the entry line to `/output/entry.txt`:

> You smell of fresh charging cable, and I have spent three floors deciding whether that is a compliment or a fire hazard.

## Run it

```sh
node main.ts
```
